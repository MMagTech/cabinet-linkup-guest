# Asking first is only for what is added here

- **Decided:** a 2P Start of one's own, for another system or frontend, in a repository of its own,
  needs no one's leave and no issue, under the rules: it only joins, and it is not called "CabinetOS
  2P Start". A new system, or anything new, to be added to this repository is asked about first, on
  an issue MMagTech agrees to, before the work. A small fix goes straight to a pull request.
  `AGENTS.md` tells an AI tool helping someone port it to say so at the start, and to draft the
  issue.
- **Date:** 2026-11-13
- **Why:** 2P Start is open source, and nothing can make a copy ask first: saying it must reads as a
  wall. For what comes here, the issue settles the choices a new system needs, such as where its
  GStreamer comes from, before weeks go into it, and the pull request is reviewed against it.
- **Numbers:** #20, "A porting guide, for a 2P Start on another system or frontend"; #21, of the same
  name.
- **Replaces:** none.
