# The porting guide is a page of its own

- **Decided:** what someone making a 2P Start for another system or frontend needs is one page,
  `docs/PORTING.md`, beside the map. The README, `CONTRIBUTING.md`, `AGENTS.md`, the map and the "A
  2P Start for another system" issue form link to it. It was not made a section of
  `CONTRIBUTING.md`.
- **Date:** 2026-11-13
- **Why:** a person porting gets one link with all of it, and `CONTRIBUTING.md` stays about working on
  this app. MMagTech chose it.
- **Numbers:** #20, "A porting guide, for a 2P Start on another system or frontend".
- **Replaces:** none.
