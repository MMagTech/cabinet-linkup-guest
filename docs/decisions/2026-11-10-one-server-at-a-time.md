# One LinkUp server at a time

- **Decided:** the first version pairs with one LinkUp server at a time. Several servers at once is for
  later, and Settings is laid out so that its Server row can become a list.
- **Date:** 2026-11-10
- **Why:** to keep the first version small and shippable. A friend usually has one friend with a
  console.
- **Numbers:** #3, "The app: a window that pairs, a live list of friends, invites and Settings".
- **Replaces:** none.
