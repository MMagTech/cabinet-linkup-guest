# One LinkUp server at a time

- **Decided:** 2P Start pairs with one LinkUp server at a time, as a console has one. Settings, Server
  changes it or leaves it. Several servers at once was planned for later on 2026-11-10, and dropped on
  2026-11-13: not at this point.
- **Date:** 2026-11-10, and 2026-11-13
- **Why:** to keep it small. A friend whose two buddies each run a server is covered by linked
  servers: one owner links the two, and the friend plays with both from the one server (CabinetOS's
  `docs/decisions/2026-11-03-linkup-servers-link-two-accounts.md`).
- **Numbers:** #3, "The app: a window that pairs, a live list of friends, invites and Settings".
- **Replaces:** the plan of several servers at once, later.
