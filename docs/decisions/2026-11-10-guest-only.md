# 2P Start joins and never hosts

- **Decided:** 2P Start only joins a friend's LinkUp game as player two. It never hosts, holds no
  games, saves or library, and never grows into a second way to run CabinetOS. The host's console stays
  in charge.
- **Date:** 2026-11-10
- **Why:** CabinetOS is a console under a TV, and that does not change. 2P Start is the one exception:
  a thank-you to the people who run CabinetOS, so a friend who cannot give a PC over to it can still
  play with them. Hosting would make it a second CabinetOS.
- **Numbers:** none.
- **Replaces:** none.
