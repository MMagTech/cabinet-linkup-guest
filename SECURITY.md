# Security

**Report a security problem privately**, not in a public issue: on this repository's Security tab,
choose "Report a vulnerability". It stays between you and the maintainer until he publishes it.

A security problem is anything that lets someone reach what they should not through 2P Start: pairing
without a code, posing as a friend or a server, reading what a friend's console seals for this one, or
reaching the computer it runs on. A problem in the protocol itself, which 2P Start shares with every
console, goes to [cabinet-linkup](https://github.com/MMagTech/cabinet-linkup/security) instead.

Say which version (Settings, About) and how to make it happen. Leave 2P Start's folder out of the
report: it holds the friend's key.

Only the latest version gets fixes. A fix ships as a new version, which Check for updates tells
friends about.
